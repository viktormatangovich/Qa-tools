# Краткий отчёт — QA Tools 2.0.0

Выполнены три этапа развития расширения для команды QA. Существующие изменения интерфейса сохранены.

1. Сравнение сессий: добавленные/исчезнувшие запросы, повторные вызовы, вложенные JSON-поля, игнорируемые поля, пороги замедления. Числовые ID и UUID объединяются в одну операцию. Профили проектов импортируются и экспортируются. История ограничена тремя сессиями за 24 часа.
2. Ручные шаги с отметками времени и привязкой запроса, текст Jira с предпросмотром, бизнес-проверки ответа, последовательности моков, фильтры и пакетные негативные проверки. Реальная отправка доступна только для явно указанных доменов локального/тестового профиля; на production — моки.
3. Экспорт API-тестов и моков Playwright, OpenAPI JSON/YAML и список неподдерживаемых проверок, просмотр WebSocket/SSE, базовые проверки фокуса, клавиатурной доступности и контраста. Интерфейс и новые отчёты на русском. Данные сохраняются без маскирования.

Проверено:
- 28 автоматических проверок логики — успешно.
- 12 браузерных сценариев — успешно: профили, ручные шаги/Jira, сохранение после перезагрузки, production-блокировка, бизнес-проверка, Playwright, настоящие ответы моков 500 → 200, негативная отправка на собственный локальный стенд, SSE/WebSocket, доступность, ширина 360 px и полный перезапуск браузера с очисткой истории.
- TypeScript, git diff --check и production-сборка — успешно.
- Версия package.json, package-lock.json и manifest.json: 2.0.0.
- Доказательства браузерной проверки: qa-request-inspector/qa-evidence/ui-results.json и team-panel-360.png.

Ограничения:
- Реальный продукт и production не проверялись: отдельный стенд не предоставлен. Все сетевые проверки выполнялись на собственном локальном стенде.
- Доступность проверяется частично; контраст — только для прямого текста на сплошном непрозрачном фоне. Это не полный аудит WCAG.
- Сложные схемы OpenAPI и внешние ссылки пока не валидируются; их список показывается в интерфейсе.
- Playwright экспортирует API-тесты и моки; генерация полного UI-сценария не добавлена. Ожидаемый статус берётся из записи и требует проверки QA.
- WebSocket/SSE: до 200 сообщений на вкладку, до 64 КиБ текста на сообщение; бинарные кадры остаются в представлении CDP.
- При закрытом браузере очистка просроченных сессий выполняется при следующем запуске; работающий браузер проверяет срок раз в минуту.
- Скриншоты, вложения и прямая отправка в Jira не добавлены по согласованному объёму.
- npm при установке зависимостей сообщил о 22 уязвимостях (3 moderate, 19 high); отдельное исправление зависимостей не выполнялось. Vite предупреждает о размере основного JS-файла около 612 КБ.

Сборки: qa-tools.zip и qa-tools-updated.zip. Внутри каждого архива manifest.json находится в корне; оба содержат одинаковую сборку 2.0.0.

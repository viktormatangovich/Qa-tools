# Reqpane — исходный код расширения

> Текущая версия: **2.3.0**

Описание возможностей, установка из архива и список изменений по версиям — в [README в корне репозитория](../README.md). Здесь только то, что нужно для разработки.

## Сборка

Нужны Node.js 22.2 или новее и npm.

```bash
npm install
npm run build
```

Затем в Chrome: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → папка `dist`.

## Команды

```bash
npm run dev      # Режим слежения — пересборка при изменении файлов
npm run build    # Продакшн-сборка в dist/
npm run zip      # Упаковка dist/ в ../qa-tools.zip (корень репозитория)
npm run release  # Сборка + упаковка
npm run test:qa  # Автоматические проверки логики
npm run test:ui  # Браузерный сценарий (нужен Chromium, путь — в QA_CHROMIUM_PATH)
npx tsc --noEmit # Проверка типов
```

`npm run zip` не требует утилиты `zip`, работает одинаково на Windows, macOS и Linux, не кладёт в архив скриншоты из `public/` и печатает SHA256 архива. Хэш нужно записать в `QA-Tools-<версия>-sha256.txt` в корне репозитория.

## Структура

```
public/
├── manifest.json        # Манифест расширения (Manifest V3)
├── _locales/            # Название и описание расширения (ru, en)
├── background.js        # Service worker: захват через chrome.debugger (CDP), правила, точки остановки, скриншот
├── captureStore.js      # Чистые функции service worker: настройки захвата, заголовки, тайминги, правка JSON (покрыты тестами)
├── mockSequence.js      # Последовательности ответов мока
└── content.js           # Поиск и подсветка в DOM, выбор элемента (ElementPicker), проверки страницы, запись шагов, запуск axe-core; внедряется по запросу

src/sidepanel/
├── App.tsx              # Разметка панели и состояние интерфейса (что выбрано, какие окна открыты)
├── hooks/               # Состояние по областям
│   ├── useCapture       #   связь с service worker: запросы, ошибки консоли, статус отладчика, остановленные запросы, скриншот
│   ├── useCaptureSettings #  сохранение лога, лимит запросов, типы ресурсов, скорость сети
│   ├── useStepRecorder  #   запись шагов на странице
│   ├── useJiraSettings  #   подключение к Jira
│   ├── useQaAnalysis    #   QA-проверка, контракт OpenAPI, проверки страницы
│   ├── useRules         #   моки и точки остановки
│   ├── useSessions      #   сохранённые сессии
│   ├── useCollections   #   коллекции, теги, закрепление, избранное
│   └── usePreferences   #   тема, размер шрифта, язык, маскирование при экспорте
├── components/          # Интерфейс по разделам; редкие окна загружаются при первом открытии (lazy.tsx)
├── qa/                  # Логика без привязки к интерфейсу: правила, контракт, отчёты, маскирование, Jira, шаги и Playwright
├── utils/               # Экспорт, импорт HAR, GraphQL, хранилище, перенос настроек, обмен со страницей
└── locales/             # Строки интерфейса: ru.ts — основной словарь, en.ts проверяется по нему типами

tests/                   # Тесты service worker на поддельном chrome API
scripts/                 # Упаковка архива, браузерный сценарий
docs/                    # Архитектура и планы
```

Подробности для работы с кодом — в [CLAUDE.md](CLAUDE.md) и [docs/qa-tools-v2-architecture.md](docs/qa-tools-v2-architecture.md), политика конфиденциальности — в [PRIVACY.md](PRIVACY.md).

## axe-core

Полный аудит доступности выполняет [axe-core](https://github.com/dequelabs/axe-core) (лицензия MPL-2.0, файл не изменяется). В сборку он попадает отдельными файлами `axe.min.js` и `axe-locale-ru.js` — их создаёт плагин в `vite.config.ts` из `node_modules/axe-core`. В стартовый файл панели библиотека не входит: панель внедряет её в проверяемую страницу только на время проверки.
